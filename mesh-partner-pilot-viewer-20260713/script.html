MESH Partner Pilot Program Script

Speaker notes for explaining the selected partner pilot support program.

Open Fullscreen Viewer

Key Positioning

  • Do not present it as general free product distribution.
  • Present it as a selective pilot with real-site validation.
  • Emphasize technical fit, feedback, and follow-up cooperation.
  • Clarify that shipping, tax, installation, wiring, and third-party equipment are separate discussions.

One-line Summary

A selective support program to test MESH in one real site, validate technical fit, collect feedback, and decide whether there is a repeatable cooperation model.

1. Opening

Introduce the program carefully

I would also like to briefly introduce our MESH Partner Pilot Support Program.

This is not a general free product distribution program. It is a limited pilot support program for selected partners who have real sites where MESH can be tested and validated.

Korean memo: “무상 지원”으로 들리지 않게 조심. 선정형 파일럿, 실제 사이트 검증이라는 표현이 핵심.

2. Purpose

Why MANNA CEA runs this program

The purpose is to work with a small number of partners and validate how MESH can be applied in real greenhouse or CEA environments.

Through this program, we want to check technical fit, installation conditions, communication stability, user feedback, and possible long-term collaboration models.

So the goal is not just to send hardware. The goal is to understand whether MESH can create value in a real site and whether we can build a repeatable cooperation model together.

3. Target Partners

Who can be considered

The program is mainly for partners who can apply MESH in practical sites, such as container farms, greenhouse builders, hydroponic operators, consultants, ag-tech companies, EPC companies, or system integrators.

We are not looking for a large number of participants. We would rather select a few partners where the use case is clear and the collaboration potential is meaningful.

4. Support Scope

What may be included

The pilot support scope may include one AI Hub, one Control Box S, up to six FR or SW control channels, up to two Air Nano sensors, and up to one MESH Link.

The final configuration will be adjusted after we check the actual site equipment, power, control method, safety conditions, and communication interface.

In other words, the listed scope is a reference ceiling, not an automatic fixed package for every partner.

5. MANNA CEA Role

What MANNA CEA provides

From MANNA CEA’s side, we can provide pilot equipment, initial configuration review, basic setup guidance, and remote technical support during the pilot period.

We can also review the site use case together and help define a practical pilot objective, such as monitoring, basic control, device integration, or operation-data collection.

6. Partner Role

What the partner needs to prepare

From the partner’s side, we would need a suitable pilot site, information about the target equipment, local installation support, basic wiring and power preparation, and feedback during the pilot operation.

The partner should also be willing to discuss follow-up cooperation if the pilot result is positive.

7. Conditions

Important restrictions

There are a few important conditions. The pilot equipment cannot be resold, transferred, disassembled, copied, or used for reverse engineering.

Also, shipping, tax, local installation, wiring, and any third-party equipment are not automatically included and need to be discussed separately.

Korean memo: 나중에 비용/책임 범위가 흐려지지 않도록 여기서 한 번 명확히 말해두는 게 좋음.

8. After Pilot

How this can lead to business

After the pilot, we would review the result together. Based on the result, we can discuss a formal BOM, pricing, supply scope, installation scope, and a possible partner cooperation model.

If the pilot proves useful, the next step could be a commercial project, a partner sales model, a joint demonstration site, or a broader technical integration discussion.

9. For University / Research Context

If explaining to Dan / WUR

This program is more commercial-partner oriented, so it may not directly fit a university research project.

However, the same idea could be adapted for a research or demonstration collaboration. If there is a suitable greenhouse, research site, or demonstration environment, we could discuss a small MESH setup for data collection, monitoring, and technical validation.

10. Closing

Short closing statement

In short, the MESH Partner Pilot Program is a selective support program to test MESH in one real site with a partner, validate technical fit, collect feedback, and decide whether there is a scalable cooperation model after the pilot.

If you think there is a suitable site or partner context, we would be happy to review it together and see whether it fits the program.
