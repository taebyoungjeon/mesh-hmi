분류 기준: 결과공고는 그렌드 공개 결과 페이지, 업체 주소는 사업자번호 기반 공개 기업정보에서 확인했다. 이번 버전은 단순 GPU/GPGPU/그래픽카드 구매, 연구용 GPU 단품, GPU 외 소모품, 서버 부속품 성격의 64건을 제외하고, GPU 서버, AI 서버, HPC/클러스터 서버, 컴퓨터서버, 워크스테이션처럼 서버/시스템 구축 검토가 필요한 공고만 남겼다. 대전 여부는 확인된 업체 주소에 대전/대전광역시/Daejeon이 포함되는지로 분류했다. NVIDIA 공식 파트너는 NVIDIA 공식 구매처/파트너 페이지 또는 업체 공개 페이지에서 NPN, Solution Provider, 공식 총판 등 명시 문구가 확인되는 경우만 표시했다.
